# Pami Kany — Banana Slice

A lightweight English-language banana slicing PWA. Drag your mouse or finger across flying bananas to score points. Avoid bombs. You have 3 lives and 60 seconds. Best score is saved locally.

## GitHub Pages
1. Create a new public GitHub repository.
2. Upload the **contents** of this folder to the repository root (index.html must be at the root).
3. Open Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Open the published HTTPS URL and test gameplay, icons, and offline installation.
5. Enter the URL into https://www.pwabuilder.com/ and generate the Windows package.
6. Test the resulting Windows package before submitting to Microsoft Partner Center.

The package generated by PWABuilder may declare the `runFullTrust` capability. If Partner Center asks for justification, accurately describe the package configuration and your use of the capability. Microsoft Store approval is not guaranteed.

## Files
- index.html: game page and interface
- game.js: gameplay logic
- manifest.webmanifest: installable PWA metadata
- sw.js: offline cache service worker
- icon-192.png / icon-512.png: application icons
- PRIVACY_POLICY.md: privacy policy text

No external assets, network APIs, or third-party libraries are used.
